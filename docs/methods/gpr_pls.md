# `gpr_pls` — Gaussian Process on PLS scores

_Group_: **Nonlinear / local** · _Registry tolerance_: `1e-08`

## Description

GPR-on-PLS — RBF Gaussian Process on PLS scores (§47)

> **Registry note** — GP head parity (sklearn `GaussianProcessRegressor` with RBF+WhiteKernel, optimizer=None) on the same PLS scores. Architecturally separated to allow GPR-on-AOMPLS reuse of `fit_gp_on_scores`.

## Explanations

### Bibliographic source

Bishop, C. M. (2006). *Pattern Recognition and Machine Learning*, §6.4 (Gaussian Processes). — combined with a preliminary PLS dimensionality reduction for spectroscopy. Verified primary link: [https://link.springer.com/book/9780387310732](https://link.springer.com/book/9780387310732).

### Mathematical principle

The method first obtains PLS scores and performs Gaussian-process regression in that reduced space with a unit-amplitude kernel, caller-supplied length scale, and caller-supplied diagonal noise level. Posterior means follow the usual kernel solve for those fixed hyperparameters.

### Appropriate uses

Gaussian-process regression on a low-dimensional PLS representation when smooth nonlinear residual structure is expected.

### Limits and validation

length_scale and noise_level are fixed inputs, amplitude is one, and no marginal-likelihood optimizer is run; seed is currently unused.

### Implementation

No marginal-likelihood search or L-BFGS hyperparameter optimization is run. The seed is currently unused, so the documented fit is deterministic for fixed inputs and parameters.
