# `fused_sparse_pls` — Fused-sparse PLS

_Group_: **Sparse** · _Registry tolerance_: `0.05`

## Description

Fused sparse PLS (§7)

## Explanations

### Bibliographic source

Implementation-specific heuristic inspired by fused sparsity; no canonical fused-lasso solver is implemented.

### Mathematical principle

The routine delegates to the current group-sparse path with all variables in one group and then applies four fixed passes of neighbour averaging to adjacent coefficient rows. It neither minimizes an L1 plus total-variation objective nor calls the Condat fused-lasso algorithm described in the historical text.

### Appropriate uses

Exploratory smoothing of adjacent regression coefficients for ordered spectral variables.

### Limits and validation

This is four fixed neighbour-averaging passes, not a fused-lasso/total-variation optimizer; l1_lambda currently has no effective influence through the delegated group step.

### Implementation

Because the delegated group threshold does not feed the returned coefficients, `l1_lambda` currently has no effective influence. `fused_lambda` controls the strength of a fixed smoothing heuristic, not a converged convex penalty solution.
