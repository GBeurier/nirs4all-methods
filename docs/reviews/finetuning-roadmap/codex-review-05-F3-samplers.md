# Codex review — F3 population samplers (ga + pso)

**Date:** 2026-07-10 · **Reviewer:** `codex exec` (read-only).
**Disposition:** 1 Blocker, 2 Major, 2 Minor. Applied: (Blocker) GA/PSO refuse to cross a population boundary until the current generation is fully resolved → ask_batch returns a partial batch (LIAR_NONE synchronous evolution); (Major) enqueue/warm-start rejected for population samplers (N4M_ERR_UNSUPPORTED) since a forced candidate can't be inverse-encoded; (Minor) PSO velocity clamp (vmax=0.5). Documented as accepted: GA/PSO emit constraint via fitness (hard mutex/requires/exclude not rejection); decode_candidate short-vector 0.5 fallback (callers pass full length). +1 regression test.

---

1. **Blocker:** `ask_batch(n > 16)` advances GA/PSO before the current population is scored, then future updates never consume those real scores. `ask_batch` is repeated `ask()` with no tells ([c_api_optimization.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/c_api/c_api_optimization.cpp:401)); GA/PSO roll when `id >= base + size` ([ga.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/ga.cpp:34), [pso.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/pso.cpp:33)) and impute unscored members as worst ([ga.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/ga.cpp:53), [pso.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/pso.cpp:62)). This contradicts the docs’ “once scored” lifecycle ([ga_search.md](/home/delete/nirs4all/_worktrees/native-hpo-phase1/docs/methods/ga_search.md:5), [pso_search.md](/home/delete/nirs4all/_worktrees/native-hpo-phase1/docs/methods/pso_search.md:5)). Fix: do not cross a population boundary with `N4M_LIAR_NONE`; either return a partial batch at the boundary, or implement/document a real constant-liar async mode and test `ask_batch(17+)`.

2. **Major:** Enqueued/forced candidates poison GA/PSO state. `ask()` passes forced params into `sample()` ([optimizer.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/optimizer.cpp:333)); `decode_candidate` overrides the trial values ([optimizer.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/optimizer.cpp:128)), but GA/PSO still associate the resulting score with the original `gen_[k]`/`pos_[k]` ([ga.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/ga.cpp:58), [pso.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/pso.cpp:72)). Fix: inverse-encode forced values into the unit vector before returning the trial, or mark forced trials external to the population; otherwise reject enqueue for these samplers.

3. **Major:** GA/PSO bypass hard constraint rejection. Base sampling retries until `constraints_ok()` ([optimizer.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/optimizer.cpp:246)), but GA/PSO decode once and return success unconditionally ([ga.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/ga.cpp:107), [pso.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/pso.cpp:104)). Conditions are applied, but mutex/requires/exclude are only fitness-handled. Fix: either add deterministic repair/rejection for decoded population candidates, or make the C ABI docs/tests explicit that population samplers may emit constraint-invalid trials.

4. **Minor:** PSO has position clamping but no velocity clamp/reset, so large velocities can keep particles saturating at `0`/`nextafter(1,0)` and waste iterations near boundaries ([pso.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/pso.cpp:90)). Fix: clamp velocity to a documented `vmax` fraction of the unit range or zero/reflect velocity when position clamps.

5. **Minor:** `decode_candidate` silently accepts a short unit vector by using `0.5` for missing axes ([optimizer.cpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/optimizer.cpp:149)) despite the declaration requiring `space_.params.size()` entries ([optimizer.hpp](/home/delete/nirs4all/_worktrees/native-hpo-phase1/cpp/src/core/optimization/optimizer.hpp:195)). Current GA/PSO pass full-length vectors, but this masks future sampler bugs. Fix: assert or hard-fail on length mismatch in debug/test builds.

Top must-fix: 1 and 2 before accepting F3 population samplers.
