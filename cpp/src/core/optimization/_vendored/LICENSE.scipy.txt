Vendored algorithm port — derived from SciPy.
==============================================

rectangular_lsap.{hpp,cpp} in this directory are a C++17 port of
scipy/optimize/rectangular_lsap/rectangular_lsap.cpp from SciPy 1.18.1
(BSD-3-Clause, author PM Larsen), https://github.com/scipy/scipy. The
control flow, tie rules and floating-point operation order are kept so the
result equals scipy.optimize.linear_sum_assignment; only index types, the
-1 sentinels and the C++ casts were adapted to the n4m warning profile.

Reference:
  D. F. Crouse. On implementing 2D rectangular assignment algorithms.
      IEEE Transactions on Aerospace and Electronic Systems 52(4):1679-1696,
      2016. doi:10.1109/TAES.2016.140952
