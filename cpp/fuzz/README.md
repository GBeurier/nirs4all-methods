# N4MM hostile-input harness

`n4m_fuzz_n4mm` exercises the existing public C ABI only:

1. header inspection with `n4m_serialization_inspect`;
2. complete allocation-free inspection with
   `n4m_serialization_inspect_model_v1` and
   `n4m_serialization_inspect_pipeline_v1`;
3. `n4m_model_import_from_buffer` only after the authoritative complete
   inspector accepts the payload.

Inputs larger than 1 MiB are refused before any ABI call. The driver neither
copies nor decodes the input and does not repair its checksum, so it cannot
become a second N4MM parser. `n4m_fuzz_n4mm_smoke` feeds hostile prefixes and
two valid, synthetic affine models through the same entry point; it also checks
that the tracked N4MM seeds still pass the current public inspector.

The two tracked seeds in `corpus/n4mm/` are generated by
`generate_seed.cpp` through the public import/export ABI, with fixed
coefficients and no real data. To regenerate and verify them on a non-Clang
developer machine:

```console
cmake -S . -B build/sec001-seed -G Ninja -DN4M_BUILD_FUZZ=ON -DN4M_BUILD_STATIC=ON -DN4M_BUILD_TESTS=ON
cmake --build build/sec001-seed --target n4m_fuzz_n4mm_seed n4m_fuzz_n4mm_smoke
./build/sec001-seed/cpp/fuzz/n4m_fuzz_n4mm_seed cpp/fuzz/corpus/n4mm
ctest --test-dir build/sec001-seed -R n4m_fuzz_n4mm_smoke --output-on-failure
```

## Build contract

The declared sanitizer configuration uses the existing CMake options and the
repository's Clang 16 CI toolchain contract:

```console
cmake --preset ci-fuzz-n4mm
cmake --build --preset ci-fuzz-n4mm --target n4m_fuzz_n4mm
```

That target links libFuzzer to the static C ABI and instruments both the
inspector/importer library objects and the harness for coverage. ASAN and UBSAN
are enabled by the preset. The manual `Sanitizers` workflow copies the two
tracked seeds into a disposable corpus and runs this target for 60 seconds with
the same 1 MiB input limit. It is intentionally not added to every push.
SEC-001 remains open pending sustained fuzzing, corpus coverage across the
other release surfaces, finding triage, and the complete security qualification
matrix.
